# BEIO Lab 周报平台

实验室学生与导师的周报工作台，包含学生注册申请、管理员审核、账号管理、学生周报、历史归档、逐项导师点评、周一编辑锁定提示和响应式界面。未登录或未获批准的学生无法打开周报首页。

管理员注册需要设置 `ADMIN_INVITE_CODE`；学生提交申请后必须由管理员点击“批准进入”。管理员移除账号采用归档方式，历史周报和点评不会被删除。

## 本地运行

```bash
npm install
npm run dev
```

## 腾讯云生产实现建议

- 前端由 Nginx 反向代理；业务 API 使用 Node.js；数据库使用腾讯云 PostgreSQL/MySQL。
- 登录使用学生账号与 Argon2 密码哈希，管理员角色单独授权。
- 服务端固定 `Asia/Shanghai`。学生写操作只允许在当期周一 00:00–23:59:59；导师评论接口不受限制。
- 锁定必须在 API/数据库事务中再次校验，不能只禁用网页输入框。
- 核心表：`users`、`report_periods`、`reports`、`report_sections`、`comments`、`audit_logs`。毕业后归档账号，不删除周报。

当前版本为可交互产品原型，使用示例数据展示学生与导师身份。接入真实账号、数据库和服务端锁定后即可投入使用。
